## Course content

This course is focused on mastering **C++ template programming** and is structured into multiple core areas:

| Section | Details |
|--------|----------|
| **Introduction to Templates** | Overview of template programming and why it is used in modern C++ |
| **Function Templates** | Writing and using function templates, type deduction basics |
| **Class Templates** | Creating generic classes and working with template parameters |
| **Template Argument Deduction** | How the compiler deduces template types automatically |
| **Non-Type Template Parameters (NTTP)** | Using constants and compile-time values in templates |
| **Template Specialization** | Full and partial specialization techniques |
| **Overloading with Templates** | Function overloading rules in template contexts |
| **Variadic Templates** | Handling multiple template parameters using parameter packs |
| **Fold Expressions (C++17)** | Simplifying parameter pack expansion |
| **Compile-Time Programming** | Using templates for compile-time logic and optimization |
| **SFINAE Basics** | Introduction to Substitution Failure Is Not An Error |
| **Modern C++ Improvements** | C++11/14/17/20 enhancements for templates |
| **Auto & Abbreviated Templates (C++20)** | Simplified template syntax using `auto` parameters |
| **Practical Template Design** | Writing reusable and scalable generic code |
| **Mini Project (Generic Container)** | Building a small container using template techniques |

## Goals of this course

The goal of this course is to develop a **deep understanding of C++ templates** and how they power the Standard Template Library (STL) and modern generic programming.

By the end of the course, you should be able to:
- Write reusable generic code using templates
- Understand compile-time vs runtime behavior
- Work confidently with modern C++ template features
- Read and understand advanced STL-style code
